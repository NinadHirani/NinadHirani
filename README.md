# Ninad Hirani

Final-year Computer Engineering student at V.V.P. Engineering College (Gujarat Technological University), Rajkot. Founder of Cybernetics Tech (2022). I work on quantum optimization and applied AI systems.

## Research

Author of a public Zenodo preprint, [Solving the Capacitated Vehicle Routing Problem Using the Quantum Approximate Optimization Algorithm: A Benchmark Against Classical Guided Local Search](https://doi.org/10.5281/zenodo.23394482), with a companion code release, [Quantum Optimization Pipeline for the CVRP](https://doi.org/10.5281/zenodo.24433714) (v1.1). The benchmark reports an honest negative result for QAOA at the tested scale, with limitations stated up front.

## Quantum algorithms lab

A lab notebook for implementing quantum algorithms: QAOA, QUBO and Ising formulations with Qiskit, Qiskit Aer and PennyLane → [quantum-algorithms-lab](https://github.com/NinadHirani/quantum-algorithms-lab).
